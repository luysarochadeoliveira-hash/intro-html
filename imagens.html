Conhecendo as imagens

Entendendo o elemento img

  • src: Indica onde está a imagem. O scr significa source/fonte = origem.
  • alt: O alt serve para descrever a imagem para quem não consegue vê-la, além de ajudar na acessibilidade. O alt significa alternative/alternativo.

Sobre os diferentes tipos de imagens

Abaixo, temos uma lista dos diferentes tipos de imagens e quando usar:

  • JPEG/JPG: Bom para fotos de produtos, paisagens e fotos pois, possui muitas cores e possui um arquivo relativamente pequeno. Não suporta transprência e caso seja comprimida várias vezes, pode perder qualidade.
  • PNG: Excelente escolha quando queremos transparência e preservar bastante a qualidade. Geralmente usamos para logos, imagens com transparência e gráficos simples.
  • WebP: Formato moderno desenvolvido para a web. Muito menor que JPEG e PNG, mantém a qualidade da imagem pois suporta compressão sem perda. Usamos para qualquer imagem comum na web.
  • AVIF: Assim como o formato WebP, é um formato moderno e também é capaz de produzir arquivos bastante pequenos/leves mantendo uma ótima qualidade. Geralmente usamos esse formato quando queremos priorizar performance.
  • SVG: O SVG é um elemento vetorial, excelente para logos, ícones, ilustrações, formas geométricas e gráficos. A vantagem desse elemento é que ele pode ser ampliado sem a mesma perda de nitidez de uma imagem baseada em PIXELS.
