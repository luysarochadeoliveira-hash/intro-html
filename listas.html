O que São listas no html?

Uma lista é uma sequência de itens relacionados entre si.

No HTML, existem principalmente três tipos de listas. Listas nao ordenadas, listas ordenadas, e listas de descrição. .

Lista não ordenada

Uma lista não ordenada é usada quando a ordem dos elementos/itens não importa

  • Arroz
  • Feijão
  • Macarrão
  • Carne
  • Café

    • Lista ordenada (ol)

    Usamos uma lista ordenada quando os itens possuem uma sequência, uma classificação ou uma ordem que precisa ser respeitada.

    1. Ferver a água
    2. Colocar o café no filtro
    3. Despejar a água lentamente
    4. Colocar o café

    Lista de descrição (d2)

    Usamos lista de descrição quando precisamos descrever algum termo.

    Para criamos essa lista utilizamos 3 elementos:

    • dl (description list) Representa a lista de descrição.
    • dt (descripition term) Representa o termo.
    • dd (data description) Representa a descrição do termo.
