Formulários HTML

O que são formulários?

Os formulários são uma das partes mais importante do html pois ajudam a introduzir uma idéia diferente.

O usuário deixa de apenas consumir o conteúdo na página e passa a fornecer dados para o sistema.

O formulário, de forma resumida, é uma área da página, destinada a coleta de informações.

Exemplos de uso

  • Login
  • Cadastro
  • Contato
  • Pesquisa
  • Comentários
  • Endereço
  • Inscrições em Newsletter

Criando um formulário básico

  • ⁢label > : Representa um rótulo ou uma etiqueta para um campo. É um recurso fundamental para a acessibilidade
  • for : Para conectarmos o nosso rótulo (label) ao input, utilizamos o atributo for. Ele serve para criar a relação com o id do input.
  • id : O atributo ID serve para identificar de forma única um elemento dentro da página.
  • type : Esse atributo serve para definirmos o tipo de input que desejamos apresentar para o usuário com base no dado que queremos coletar.
